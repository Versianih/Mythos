# Repository Structure

```bash
mythos/
├── global/
├── daedalus/
│   ├── 3d/
│   ├── code/
│   ├── docs/
│   │   └── imgs/
│   ├── pcbs/
│   └── README.md
├── horus
│   ├── code/
│   ├── docs/
│   │   └── imgs/
│   └── README.md
├── README.md       <-- This file
└── README-pt-br.md

```

Each robot has its own folder and individual documentation. Shared and general-purpose code and structures are stored and documented in the [`global/`](./global/) folder.

# Robots

- **[Daedalus](./daedalus/)**: Line-following robot equipped with 7 infrared sensors controlled by an **ESP-WROOM-32U**.

- **[Hórus](./horus/)**: 15x15 cm, 1 kg mini-sumo robot controlled via a PS4 controller, using the **ESP-WROOM-32U** as its microcontroller.
